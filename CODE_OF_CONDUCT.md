# Code of Conduct / 行動規範

We welcome questions, bug reports and contributions from people with different backgrounds. Be respectful, specific and patient. Review the change or evidence, not the person. Harassment, discrimination, threats, doxxing and deliberate disruption are not acceptable.

Oathraの質問・不具合報告・貢献は、立場や経験にかかわらず歓迎します。相手ではなく変更内容や証拠について、具体的かつ丁寧に話してください。嫌がらせ、差別、脅迫、個人情報の公開、意図的な妨害は認めません。

## Reporting / 報告

Do not include phone numbers, credentials, recordings or private call content in a public issue. For a conduct concern, contact the maintainer through the [FORIFOR GitHub profile](https://github.com/FORIFOR). If a private channel is unavailable, open a Discussion with a non-sensitive summary and ask for private follow-up. Security vulnerabilities should not be disclosed publicly; use GitHub's private security reporting flow when it is available.

公開Issueには電話番号・認証情報・録音・私的な通話内容を含めないでください。行動規範に関する懸念は[FORIFORのGitHubプロフィール](https://github.com/FORIFOR)から運営者へ連絡してください。非公開経路が使えない場合は、機密情報を含まない概要だけをDiscussionに書き、非公開での対応を依頼してください。脆弱性は公開Issueに書かず、利用可能な場合はGitHubの非公開セキュリティ報告を使ってください。

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) principles, adapted for this repository's privacy and evidence requirements.
