Give AI agents a phone —
and proof of what happened.

Oathra is a runtime for agents that call, negotiate and act on the real world. Every field in the result is backed by the other party's own words. Completion is decided by code, never by asking the model whether it succeeded.

  • Playable simulator, no API key
  • Real phone calls in one command
  • Verified outcomes, not summaries
  • Bring your own carrier & model

Play

Call

Same runtime, real phone. Bring your own carrier. Bring your own model.

Twilio keeps its direct media-streams fast path. Plivo and any SIP trunk go through a SIP gateway (LiveKit by default, Cloud or self-hosted). The voice engine is a separate choice: GPT-Live is recommended because it was simply the most natural on our test calls; a Deepgram + LLM + TTS pipeline is there when you want control or lower cost.

For everything else, one guided click — never a wall of SIP settings.

Providers that need a human (caller-ID verification, geo permissions, regulatory bundles) return a user_action step with a link; Oathra polls until it is done. oathra phone test has three levels — Local ¥0, Gateway ¥0, PSTN paid — so you stop paying for a phone minute every time you fix a bug.

Prove

"予約できました" is not evidence.

Oathra returns a VerifiedResult. Each field is anchored to an utterance from the other party (and to audio on real calls). Refusals never become offers, corrections supersede, hedges do not confirm, and a confirmation goes stale if the deal changes after it was spoken. Ten thousand mutated callees — never-confirm, wrong restate, negate-then-offer, silent hangup, echo trap — produce zero false completions.

{
  "field": "time",
  "value": "19:30",
  "source": "callee",
  "transcript": "19時はいっぱいですが、19時半でしたら空いております。",
  "span": "19時半",
  "explicit": true,
  "verified": true,
  "note": "accepted with value restated by caller",
  "audio": { "startMs": 14210, "endMs": 18960 }

Status · v0.1 launch candidate

What is real today, and what is not.

  • CallContract, evidence engine, deterministic completion
  • Simulator, Arena (Watch / Play), Battle, Replay, time travel
  • Scenario DSL with a CI gate: 0 / 10,000 adversarial runs
  • Twilio direct path, verified on real calls to a Japanese mobile
  • GPT-Live voice engine, verified on a 6-minute real call
  • Phone Layer: setup, doctor, three-level test, routing with fallback
  • Plivo / custom SIP via LiveKit: implemented from provider docs, PSTN not yet verified
  • Telnyx, Wavix, Sinch providers; ElevenLabs TTS
  • Dual-ASR safe path for amounts and numbers; 650 ms pipeline target
  • MCP server (call · inspect_call · intervene · cancel_call) — v0.2

Numbers on this page come from our own runs and are reproducible with the commands shown. We publish no benchmark we did not measure.
