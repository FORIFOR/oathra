# プロダクトレビュー（初回体験の点検）

日付: 2026-09-12 / 対象: Arena・CLI の初回体験 / 基準: 「最高精度で洗練されたもの。AI が作った感をなくし、日本人向けに」

## 点検した経路

1. `pnpm demo` → ブラウザで Arena（日本語 / 英語、ライト / ダーク）
2. Arena「AI同士を見る」→ レストラン予約 → 結果カード → 詳細（タイムライン）
3. Arena「自分が電話に出る」→ レストラン予約 → 入力欄 → 証拠の増え方
4. 発表モード `?present=1&theme=dark`（動画撮影用、1920×1080）
5. CLI: `oathra --help`、`oathra play`、`oathra eval`、`oathra phone list`、`oathra doctor`

## 直したこと

### Arena
- **日本語対応**を追加。`?lang=ja|en`、未指定ならブラウザの言語で自動判定。見出し・モード・状態表示・ミッション / 証拠・結果カード・詳細ドロワー・Play モードの案内・トースト・空状態まで、画面上の文言をすべて辞書経由にした。
- シナリオ名を日本語表示（レストラン予約 / 無理難題ホテル / まとめ買い交渉 / シリアル番号の復唱 / 満席の罠 / 友達と雑談）。英語名は小さく併記。
- 難易度は「かんたん / ふつう / むずかしい / 極」。組み込みの台本エージェントは「組み込みエージェント」と表示（内部名 `scripted` を出さない）。
- 日本語モードでは、英語の大文字モノスペース見出し（AGENT / CALLEE / MISSION など）を廃し、和文サンセリフ + 適切な字間に変更。行間もやや広めに。
- 証拠パネルの件数を「検証済み / 総数」に変更（未確定しか無い時に「0」と出て混乱していた）。証拠が無い時は「まだ証拠はありません」。
- 証拠カードの引用は 1 行で省略し、ホバーで全文（title 属性）。
- ミッション一覧のカードにホバー背景とキーボードフォーカスリングを追加。角丸をコントロール 4px / カード 8px に統一。
- Play モードで相手側アバターに「あなた」と二重表示していたのを、記号 + 名前「あなた」に整理。
- 「実電話」パネルの文言を実態に合わせた（CLI では今日から使える。Arena からの発信は次の版）。プロバイダ一覧を Twilio / Plivo / 自前の SIP / Telnyx（v0.2）に修正。
- 英語モードでは英語の説明文、日本語モードでは日本語の説明文を優先。

### CLI
- `oathra --help` を「Try it / Real phone / Trust / Extend / Check」に整理し、各行を 1 文で説明。ドキュメント URL を実在のリポジトリに修正。
- `demo` の起動バナーと `doctor` の要約の文言を具体的に（「Ready」の羅列をやめ、何ができるかを書く）。

## 未対応（スコープ外。優先度順）

1. **CLI の日本語化**。`oathra` の出力は英語のまま。`--lang ja` または `OATHRA_LANG=ja` で `play` / `doctor` / `phone` の主要メッセージを日本語にすると、日本人向けの一貫性が上がる。
2. **結果カードの項目名**（date / time / partySize / confirmed）がキー名のまま。シナリオ側にラベル（`labels: { time: "時刻" }`）を持たせるか、共通辞書で「日付 / 時刻 / 人数 / 確定」に置き換えたい。スキーマ変更が要るため未着手。
3. **Arena から実電話を発信する導線**がない。`phone.yaml` があれば「実電話」タブから `oathra call` 相当を起動できると、動画で見せた体験と実際の体験が一致する。
4. **Play モードの最初の 1.5 秒**。相手（人間）が何も言わないと AI が先に話し始める。人間相手のときは 4〜5 秒待つか、「電話に出る」ボタンで開始する方が自然。
5. **シナリオ YAML の `title` が英語のみ**。今回は app.js の対応表で日本語化したが、YAML に `title_ja` を持たせる方が拡張しやすい（スキーマ変更）。
6. **終了理由の表示**（`agent_hangup` など）が内部値のまま。日本語ラベルに置き換える。
7. **詳細ドロワーのタイムライン**はイベント名が内部名（`transcript.final` など）。開発者向けなので許容範囲だが、要約列は日本語化の余地がある。
8. **フォント**。和文はシステムフォント（Hiragino）依存。Web フォント（Noto Sans JP）を同梱するとどの OS でも同じ見た目になるが、サイズ増と引き換え。
