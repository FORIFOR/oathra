# First-user outreach — 2026-09-21

Status: **publication drafts, not a report of acquired users or stars**. This document accompanies [the first-run guide](FIRST_RUN.md). The maintainer owns Oathra. All outreach must disclose that affiliation rather than pose as a third-party endorsement.

## One audience and one useful first action

Audience: developers already building outbound voice agents who need to distinguish an agent's success claim from the other party's confirmation.

First action: try the existing no-install transcript checker. Do not require replacing a telephony provider, signing up, starring or paying to access the public checker. A useful result or a small reproducible counterexample is the goal of the first visit.

Positioning: **Check a voice agent's completion claim without replacing your voice stack.**

The checker evaluates declared conversation-level conditions with bounded language rules. It does not prove that an external reservation database accepted a booking, does not guarantee success on arbitrary calls and does not replace workflow-specific evaluation.

## Measurement: targets are not results

A suggested first checkpoint is **five independent people attempting the same checker workflow**. This is a target, not an existing user count or a prediction. Record their voluntary feedback, whether they reached a result, and the blocker. Avoid collecting transcript contents or personal account identifiers.

For reach and retention, distinguish:

- Post impressions and actual link clicks, when the publishing platform supplies them.
- Repository visitors from owner-authorized GitHub traffic data, when available.
- Net change in the public aggregate star count; a change alone does not establish attribution to a specific post.
- Independent attempts and reproducible feedback, not self-runs or synthetic fixtures counted as users.

The UTM parameters in these drafts are **labels only**. No website analytics, event collection, click counter, star attribution, workflow or scheduled monitoring is installed by this documentation change.
