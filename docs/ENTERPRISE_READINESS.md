## 実電話100件の未完了ゲート

管理下のテスト番号、応答担当者またはテスト用受電系、録音同意、発信時間帯、通話料金上限を確定してから行います。今回の作業では発信していません。既存の実電話記録を今回の100件の分母に加算しません。

各試行について、試行ID、実回線/構成・バージョン、相手側の事実ラベル、最終判定、誤完了、タスク成功、人間修正、切断、ASR誤り、応答遅延サンプル、実利用料金を記録します。成功/部分成功/失敗/留守電/拒否/聞き返し/転送/保留/騒音/早口/方言/途中切断を含め、失敗や接続不可も分母に残します。

0 false completions/100件を得ても将来の誤完了ゼロを保証するものではありません。料金は契約回線・音声モデル・実通話秒数の明細で計算し、シミュレーターの0 USDを実通話料金として提示しません。

## データ・ライセンス・導入

台本シミュレーターは端末内で実行可能。実電話では選択した電話会社・音声/モデル提供元へ会話が渡り、通話記録は運用者の保存先に残ります。Apache-2.0。提供者との契約条件は別途適用されます。

L2は番号管理、発信時間/予算/回数、同意と録音保持、人間への引き継ぎ、顧客間分離を実環境で確認してから。L3のSLA・回線冗長化・運用監視は今回の試験範囲外です。[導入相談](https://forifor.github.io/oathra/#business)。
