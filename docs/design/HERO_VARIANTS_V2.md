**推奨: A。** 理由は、提案書の順番「何ができるか分かる → 実物を見て納得する → 試す」を最初の画面だけで満たすのが A だけだから。「試す」がスクロールなしで始まり、押した結果が同じ画面で変わる。

A を採用する場合の構成案: ヒーロー = A。その直後に C の再生機を「実際の通話」として置く（実データの説得力を 2 番目に回す）。B の実画面 2 枚は現行の `#screen` 節にそのまま残す。
