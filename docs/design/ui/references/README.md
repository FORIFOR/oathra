# Reference images

ここへ権利上利用可能な参照スクリーンショットを置く。参照画像はこのキットには同梱していない。

各画像について記録:
- 出典URLと取得日
- 対象がhomepage / app / desktopのどれか
- viewport、DPR、ブラウザ、ページ位置、表示状態
- 採用したい属性: 例「見出しとデモの主従」「操作直後の反応」
- 模倣しない属性と理由
- 誰が画像を実際に開いて確認したか

参照先のHTMLだけを取得した場合はVISUAL UNVERIFIED。
LPのhero動画やモックが、実製品にそのまま存在するとは限らない。
新しい画面の比較時は、条件をそろえ、必要ならブランドを隠してA/B順序を変える。

現在、参照画像は置いていない。競合や他製品との比較は、画像を置いて同条件で見るまで主張しない。
