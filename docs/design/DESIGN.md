# DESIGN — Oathra サイトの設計ルール

作成 2026-09-13。6 サイト共通の「仕上げの基準」と、Oathra 固有の見せ場を分けて書く。

## 方向

「電話業務を任せられるか判断できる精密さ」。読みやすい数値と時刻、細い区切り線、限定的なステータス色。派手さより、10 秒見たときに製品の違いが分かること。

## 色

提案書の初期案は濃紺＋淡いシアンだが、**明るい基調を維持する**。理由: 2026-09-12 に暗い配色の版を「AI っぽい」と却下しているため。濃紺は使わない。

| 役割 | 値 |
|--|--|
| 背景 | `#fbfaf7`（暖白） |
| パネル | `#ffffff` |
| 文字 | `#17181a` / 補助 `#3b3e44` / 控えめ `#6c7078` |
| 区切り線 | `#e3e0d8` / `#edebe5` |
| アクセント（1 色） | `#c4401c`（朱）。相手の発言に紐づく証拠、CTA、強調にだけ使う |
| ステータス | 確認済み `#1f7a3e`、未確定 `#a86300`、失効 `#b3261e` |

アクセントは「相手の発言が根拠になった瞬間」を示す色として一貫させる。装飾には使わない。

## 書体・寸法（共通基準）

| 項目 | 基準 |
|--|--|
| ページ最大幅 | 1,200〜1,280px（現行 1,040px → 1,200px に広げる） |
| 長文の読み幅 | 600〜720px |
| 本文 | PC 18px、モバイル 16〜18px、行間 1.7〜1.9 |
| 主見出し | PC 48〜64px、モバイル 32〜40px。日本語は `text-wrap: balance` と手動改行で行末の「た。」「い。」を残さない |
| セクション間隔 | PC 96〜128px、モバイル 56〜80px |
| 主ボタン | 高さ 48px |
| 書体 | 見出し Zen Kaku Gothic New、本文 IBM Plex Sans JP、等幅 IBM Plex Mono（数値・コマンド・時刻のみ） |

英語版は同じ数値をそのまま使わず、見出しサイズと改行を英語用に調整する。

## Oathra 固有の見せ場: 「発言から証拠へ」

サイトで一つだけ作る動き。左に通話、右に証拠。相手の一言が入った瞬間に右側の項目が埋まる（または埋まらない）。これ以外の動きは作らない。

- 主役は実際の通話記録（`site/data/call-gpt4o-mini.json`、保存イベントの再描画）と、店員役の返事を選んで判定を確かめるサンプル
- サンプルには「実際の電話は発信されません」「判定は同じエンジンで検証した記録」と明記
- 音声は自動再生しない。動画はポスター画像を先に出し、操作で読み込む

## 参考から借りるもの／借りないもの

| 借りる | 借りない |
|--|--|
| 実画面・実データを大きく見せる構図 | 有名サイトの配置・コピー・素材の複製 |
| 一箇所に集中した意味のある操作 | 複数の背景エフェクト、発光する球体、無関係なグラデーション |
| 実装前に色・書体・余白を固定すること | 読めない極小ダッシュボード、同じ形の機能カードの連続 |
| ヒーロー 3 案を作って選ぶ工程 | 一発生成、赤い警告、ハッカー風文字列、意味のないネットワーク図 |

## 導線

- 主 CTA は 1 つ: 「予約シミュレーションを試す」（ページ内サンプルへ）。次に `npx oathra demo`
- GitHub はヘッダーと体験後。トップの主ボタンを「Star」にしない
- 導入相談は GitHub とは別の入口。現時点の実体は GitHub Discussions。非公開フォームは未設置（設置するまで「非公開で相談」とは書かない）

## 動画の共通ルール

一本で一つの用途だけ。ズームは読んでほしい場所にだけ。UI の文字が読める倍率で止める。字幕を付ける。`prefers-reduced-motion` で自動再生しない。
