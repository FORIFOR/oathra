# DESIGN — Oathra サイトの設計ルール

作成 2026-09-13、更新 2026-10-02。公開トップとログ検証を対象に、実画面の反復レビューから更新した。Gateway の詳細は `ui/brief-gateway.md`、観測と未検証事項は [品質記録](../quality/award-craft.md) を参照する。

## 方向

「完了には、相手の言葉を。」既存の音声AIに完了判定だけを追加できることを最初に伝える。発言・証拠・判定の関係を主役にし、余白と文字の階層で操作を案内する。ログ検証・SDK と、公開準備中の電話サービスを混同させない。

## 色

**明るい基調を維持する**。2026-10-02 は Gateway の Ring Zero テーマと連続する Mist・墨・Jade へ整理した。以下は公開サイトの値。Gateway のトークンは `ui/brief-gateway.md` を維持する。

| 役割 | 値 |
|--|--|
| 背景 | `#f6f8f6`（明るい Mist） |
| パネル | `#ffffff` |
| 文字 | `#182b26` / 補助 `#465951` / 控えめ `#63756c` |
| 区切り線 | `#d5dfd7` |
| アクセント（1 色） | `#267657`（Jade）。ロゴと証拠の意味に結び付く強調。主CTAは墨色 |
| ステータス | 確認済み Jade、未確定 `#885b1f`。色に加えて必ず文章で状態を示す |

アクセントは「相手の発言が根拠になった瞬間」を示す色として一貫させる。装飾には使わない。

## 書体・寸法（共通基準）

| 項目 | 基準 |
|--|--|
| ページ最大幅 | 最大 1,280px |
| 長文の読み幅 | 600〜720px |
| 本文 | PC 16px、モバイル 14px を中心に、主要コピーは大きく。行間 1.7〜1.9 |
| 主見出し | PC 40〜66px、モバイル 32〜46px。日本語は `text-wrap: balance` と手動改行で行末の「た。」「い。」を残さない |
| セクション間隔 | PC 74〜86px、モバイル 36〜48px |
| 主ボタン | 高さ 48px |
| 書体 | 外部フォントを必須にせず、Inter / Helvetica Neue / システムの日本語書体。数値・コマンド・時刻にシステム等幅書体 |

英語版は同じ数値をそのまま使わず、見出しサイズと改行を英語用に調整する。

## Oathra 固有の見せ場: 「発言から証拠へ」

主な操作は、同じ保存記録の3時点を選び、発言から何が確認できたかを読むこと。相手の発言と現在の証拠を近くに配置する。無関係な背景エフェクトや自動進行を足さない。

- 主役は公開済みのモデルとホテルシミュレーターの交渉記録（`site/data/recorded-check.json`）。時点までの発言を同じ実エンジンで検査する
- 「Arena シミュレーターの保存記録であり、実電話ではない」と明記。新たな架空会話は作らない
- 自由入力の判定と記録再生は日英の `lab.html` へ残し、トップから明示的にたどれるようにする
- 音声は自動再生しない。動画はポスター画像を先に出し、操作で読み込む

## 参考から借りるもの／借りないもの

| 借りる | 借りない |
|--|--|
| 実画面・実データを大きく見せる構図 | 有名サイトの配置・コピー・素材の複製 |
| 一箇所に集中した意味のある操作 | 複数の背景エフェクト、発光する球体、無関係なグラデーション |
| 実装前に色・書体・余白を固定すること | 読めない極小ダッシュボード、同じ形の機能カードの連続 |
| ヒーロー 3 案を作って選ぶ工程 | 一発生成、赤い警告、ハッカー風文字列、意味のないネットワーク図 |

## 導線

- 主 CTA は「ログを検証する」（`check.html`）。次に SDK / CLI の導入ガイド。一般向け電話サービスを利用可能と表示しない
- GitHub はヘッダーと体験後。トップの主ボタンを「Star」にしない
- 導入相談は GitHub とは別の入口。ページ内の非公開の相談フォーム（`#business`、82c0dc8 で追加）。GitHub Discussions は公開の相談先

## 動画の共通ルール

一本で一つの用途だけ。ズームは読んでほしい場所にだけ。UI の文字が読める倍率で止める。字幕を付ける。`prefers-reduced-motion` で自動再生しない。
