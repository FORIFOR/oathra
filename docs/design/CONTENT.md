## サンプル（ブラウザ内、実電話なし）

シナリオ: レストラン予約。ミッション = 9月12日、19時以降、2名、確定。
店員役の返事（3 つ）と、その後の証拠欄。値はエンジン単体で検証した記録（`docs/launch/miscompletion-cases.md`）。

| 店員役の返事 | 証拠欄の変化 | 確定 |
|--|--|--|
| 「たぶん大丈夫ですが、まだ確定ではありません」 | 何も増えない（曖昧語があるため同意にも確定にもならない） | 未確認 |
| 「19時は満席です。19時半なら空いています」 | 時刻 19:30 が「提案・受諾待ち」で入る。19:00 は入らない | 未確認 |
| （AI「では19時半でお願いします」の後）「19時半に2名様でご予約承りました」 | 時刻 19:30 ✓、人数 2 ✓、確定 ✓（相手） | 確認済み |

注記文: 「サンプルです。実際の電話は発信されません。判定結果は同じ証拠エンジンで検証した記録です。」

## 数字（すべて自分で計測、コマンドで再現可能）

| 表示 | 裏づけ | 添える条件 |

| 3 + N | Twilio（検証済み）· Plivo · SIP（未検証）· 自作 | 未検証を併記 |

## 実際に電話してみた記録

現行サイトの 3 回分をそのまま使う（11.8 秒 → 2.2 秒 → 約 0.4 秒、留守番電話、割り込み誤認）。総額数百円の注記も残す。

## 判定ルール 6 つ

現行サイトの `ul.rules` をそのまま使う。裏づけは `packages/evidence/src/extract.ts` の HEDGE_RE / REFUSAL_RE / CONFIRMATION_RE、`engine.ts` の失効判定。
