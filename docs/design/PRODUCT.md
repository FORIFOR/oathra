# PRODUCT — Oathra は誰の、どの仕事を、どう変えるか

作成 2026-09-13。サイト制作の前提。ここに無い主張はサイトに書かない。

## 一文で

AI に電話をかけさせて予約・注文・確認を取らせる。**結果が本当に取れたかは、AI の自己申告ではなく相手（店側）の発言から取り出した証拠でコードが判定する。**

## 誰の、どの仕事

| 使う人 | 今の仕事 | Oathra でどう変わるか |
|--|--|--|
| 音声・電話 AI を作っている開発者 | 「予約できました」と言う AI を信じるしかない。判定は LLM の要約か、人が録音を聞き直す | 完了判定を決定論のルールに移し、各項目が相手の発話（実電話では音声区間）に紐づく。誤完了を敵対的シミュレーションで数えられる |
| 予約・受付・確認電話を抱える事業者（将来の商談相手） | 電話を人が取る／かける。自動化しても結果の信頼性が担保できない | 「取れた／取れていない」が証拠つきで返る。まずシミュレータで挙動を確認してから回線を繋ぐ |
| 遊びに来た人 | — | API キー不要で AI 同士の通話を見る、自分が店員として出て AI を騙してみる |

## 実装済み（v0.1.0、npm 公開済み）

- CallContract、証拠エンジン（`packages/evidence`）、決定論の完了判定。日時・人数・金額・電話番号・シリアルの抽出は正規表現で、LLM は使わない
- 判定ルール: 断りは提示にならない／言い直しは上書き／曖昧な返事は確定にならない／確定できるのは相手だけ／条件が後から変われば確定が失効／引き下がりは受諾ではない
- シミュレータ、Arena（AI 同士を見る／自分が電話に出る）、Battle カード、Replay、時点への巻き戻し
- Phone Layer: `setup phone`、`phone doctor`、3 段階テスト（Local ¥0 → Gateway ¥0 → PSTN 有料）
- 音声エンジン: GPT-Live、OpenAI Realtime、Deepgram + LLM + TTS
- 0.1.1（公開待ち）: 曖昧な返事への確認、AI の挨拶で即終話、証拠パネルの重複畳み込み、Play モードの「誤完了を誘ってみる」ボタン

## 検証済み（自分で計測、コマンドで再現可能）

- `oathra eval --adversarial 10000` → False Completion 0 / 10000（**用意した変異の範囲での 0**。実通話の指標ではない）
- Twilio 直結 + GPT-Live で実通話 3 回。最初の返答まで約 0.4 秒、6 分 25 秒・112 ターン・エラーなし
- 店員役の 5 つの言い回し（`docs/launch/miscompletion-cases.md`）が誤完了にならないことをエンジン単体で確認
- テスト 127 件、CI で依存方向を検査

## 未検証

- Plivo と Custom SIP（LiveKit 経由）: ドキュメント準拠で実装、PSTN 未検証
- 実通話での誤完了率: 実通話は 3 回のみ。統計として出せる数字はない
- 他者による試用: 2026-09-13 時点で 0 件。試用依頼は下書き済み、未送信
