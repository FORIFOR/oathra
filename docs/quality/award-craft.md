# 公開サイト・サービス入口の品質改善

2026-10-02 JST。対象は公開サイトの日本語・英語トップとログ検証、Gateway のログイン・AI連携。基点は `db56271` と既存の未コミット変更。変更を実装し、実ブラウザの観測から再修正する。受賞、外部審査への合格、一般公開の完了を自己採点で認定しない。

その後の「アプリ全体を対象にする」という指定に基づく、ログイン後の操作画面の改善・検証は [アプリ全体の品質記録](app-craft.md) に分けて記録する。以下の入口向け検証を、アプリ全体を検証済みという意味には広げない。

## 基準と実装への落とし込み

参照した一次資料:

- [Awwwards の評価基準](https://www.awwwards.com/about-evaluation/): Design 40%、Usability 30%、Creativity 20%、Content 10%。見た目だけを直して操作や内容を残す判断にはしない。
- [Webby Awards の審査基準](https://www.webbyawards.com/judging-criteria/): ウェブサイトの内容、構造・ナビゲーション、ビジュアルデザイン、機能、インタラクティビティ、革新性、体験全体。利用者が目的を終えられるかを含めて見る。
- [FWA の公式25周年ページ](https://thefwa.com/FWA25/25.html): デジタルデザイン・開発の創造性、独自性、技術的な卓越性。数値配点の一次資料は確認できていないため、配点や合格点を作らない。

これらを、本製品では次の確認可能な条件へ変換する。下記は Oathra の実装ゲートであり、各賞の公式な合格基準ではない。

| 観点 | 確認すること |
| --- | --- |
| 造形と一貫性 | 明るい背景、墨色の操作、ロゴ・検証済み証拠の Jade。見出し・本文・補足の階層と、画面幅に応じた余白が揃う |
| 製品固有の体験 | 実際の保存記録の「相手の言葉 → 条件 → 判定」を触って理解できる。架空の通話実績や飾りの成果グラフを置かない |
| 初回導線 | 受付停止中でも、公開ログ検証と連携の説明にたどり着ける。Claude Code と ChatGPT の手順を選んで読める |
| 操作と状態 | 接続・ログイン・許可・解除・失効・エラーで、次の操作と結果を誤認しない。電話の個別承認を装飾のために省略しない |
| アクセシビリティ | 狭幅で横スクロールを生まず、キーボードで操作でき、フォーカスが見え、動きを減らす設定を尊重する |
| 技術と誠実さ | 実 API・実判定エンジンを使う。未公開の電話サービス、ローカル MCP、Arena のシミュレーション記録を区別する |

## 改善前の観測

隔離 Gateway を既存 DB の native backup から起動した。worker は未起動、外部 provider の資格情報は渡さず、登録・購入・発信を停止し、予算はゼロ。架空の商品・連絡先・電話・決済を作っていない。

- `/` と `/app/` は停止案内とログインだけで、初めて来た人が価値を理解して試せる入口が見えなかった。
- `/connect` の接続 URL はデスクトップで y=1273、390px 幅で y=1394。モバイルの Claude コマンドは y=1800 と、主操作がログイン欄の下に埋もれていた。
- 各入口のロゴ・配色・余白・認証手段に差があり、同じサービスとしての連続性が弱かった。
- 公開サイトは一般向け電話サービスと読み違えやすく、証拠と判定の体験より長い説明・コマンドが先に来ていた。

[独立した改善前レビュー](evidence/2026-10-02-craft/before-independent-review.json)。独立担当は既存のセキュリティレビュー履歴を持つため、未見の人間によるユーザーテストとは区別する。改善前画像には、撮影時点の dirty source 全体のハッシュがない。

## 選んだ構成

- 公開サイト: 「証拠の見開き」。実記録の発言と、その時点で確認できた条件・判定の関係を一つの体験として見せる。動画を大きく見せる案と縦長の監査履歴案より、ログ検証と SDK 導入への短い導線を優先。
- ログイン: 左に価値と利用できる入口、右にログイン。単にフォームを縮める案と未ログインのダッシュボード案より、停止中でもできることが伝わる構成を選択。
- AI連携: 接続設定を主列、ログインを補助列へ。選んだツールの手順を表示。OAuth の許可と電話の確認は専用の見出しと一列の構成に切り替え、設定案内を混在させない。

## 検証の記録

- 公開サイトは日本語・英語のトップ、ログ検証、従来ラボを3ラウンドで改善した。第3ラウンドは49件 PASS。[サイトの操作・画面記録](evidence/2026-10-02-craft/site-after-c.json)。実際に公開している Arena の保存記録を使い、価格提案時の未完了、最終確認時の完了、根拠の引用・時刻、消去、形式エラーと復帰、キーボード操作、動きを減らす設定、相対リンク・媒体、360 / 390 / 720 / 1440px のレイアウトを確認した。架空の会話は追加していない。主要テキスト8系統の実計算コントラストは両言語とも4.5以上。全要素の WCAG 適合試験ではない。
- Safari はサイト実装に参加していない担当が別途実操作した。[独立したサイトレビュー](evidence/2026-10-02-craft/site-independent-review.json)。主ボタンの背景が薄くなる観測を受け、背景色のアニメーションを除去し、再読み込み後のトップ・ログ検証で可読性の回復を確認した。保存記録の判定・再計算・消去・履歴も確認。非空入力の編集と形式エラーは、この独立担当では静的レビューのみ（Chrome の実操作は上記記録）。390px の通常タップ後の結果位置は操作環境の制約により未確認で、欠陥の不在とは扱わない。
- その未確認箇所を root が Chrome の390×844px画面で追加確認した。検証ボタンを画面下80pxに置いて実ポインターで押すと、結果が y=957px に残り見えない問題を両言語で再現した。[修正前](evidence/2026-10-02-craft/site-mobile-result-before.json)。760px以下で結果が画面外にある成功時だけ、アニメーションなしで判定欄へ移動するよう修正。両言語で y=95px に判定全体が収まることを同じ操作で再確認し、画像も目視した。[修正後と対象ソースのハッシュ](evidence/2026-10-02-craft/site-mobile-result-after.json)。公開記録のJSON経路を実操作。ラベル付きログは共通の表示処理を使うことを静的確認した。Safariの通常タップおよび実機モバイルの確認を代替したとは扱わない。
- 既存サイトの全 section ID と再生入口を基点の HTML から抽出し、旧 URL 41件が同じ言語の対応箇所へ移ることを実ブラウザで確認した。[旧リンクの回帰記録](evidence/2026-10-02-craft/site-legacy-links.json)。従来のラボ、保存記録プレーヤー、動画は残している。第3ラウンド後の旧リンク追加はこの別記録で検証し、同時点の撮影と混同しない。
- localhost / 127.0.0.1 / IPv6ループバックのプレビューでは、既存の利用集計イベントを送らないようにした。従来ラボの公開済み操作を日本語・英語で実行し、集計送信が0件であることを確認。[ローカル集計除外の記録](evidence/2026-10-02-craft/site-local-analytics.json)。相談フォームは変更・送信していない。本番での本人アクセスや全自動化を識別できるようになったという意味ではない。
- Gateway の3入口を 320 / 360 / 390 / 768 / 1440px の5幅で撮影し、15画面で横方向のはみ出しと実行時例外がないことを確認した。[最終画面の観測](evidence/2026-10-02-craft/final-first-use.json)は対象ファイルの SHA-256 と検証中不変を記録している。
- Gateway の操作は38件 PASS。[操作記録](evidence/2026-10-02-craft/final-interactions.json)・[独立レビュー](evidence/2026-10-02-craft/final-independent-review.json)。タブの矢印 / Home / End、ネイティブクリップボードへのコピー一致、空欄の送信抑止、詳細の開閉、通信断と復帰、暗色、動きを減らす設定、無効な確認 URL を実操作した。独立担当は補足7枚を含む22画像を目視し、観測範囲に未解決の P1 / P2 はない。`phone/account.js` のハッシュは最終レビュー時のみ採取し、撮影中不変の証明とはしていない。
- 変更後の実 OAuth / MCP / ブラウザ回帰は48件 PASS。[記録](evidence/2026-10-02-craft/oauth-after-ui.json)。実際の既存アカウント・隔離した DB・HTTP コールバックで、許可・拒否・解除・セッション失効時の非表示を含めた。架空の営業レコードや実決済では代替していない。
- Gateway の隔離検証前後で業務データ35件のハッシュが一致した。検証プロセスの本人性を確認して終了し、一時 DB を削除した。[停止・データ保全記録](evidence/2026-10-02-craft/preview.json)。公開サイトの静的ローカルプレビューはレビュー用に残している。
- `pnpm build`、`pnpm lint:deps`、`pnpm build:site`、変更した Gateway JavaScript の構文検査、`git diff --check` は成功した。サイト2エントリの `strict` / `exactOptionalPropertyTypes` / `noUncheckedIndexedAccess` を有効にした型検査では、新しい時点選択処理の3件を検出・修正して再検査を通した。

反復は、(A) 構図・主操作、(B) スマホの入口・改行・説明の重複、(C) 状態・キーボード・通信障害と既存機能の維持、の順に実画面から修正した。CSS `zoom:2` と720pxの折り返しは確認したが、ネイティブの200%ズームや WCAG 全項目の適合認定ではない。

サイトの各ラウンドのソースと最終修正を区別するため、[最終ファイルと証拠のハッシュ](evidence/2026-10-02-craft/site-final-manifest.json)・[サイト個別レビュー](evidence/2026-10-02-craft/site-review.md)を保存した。公開 push / デプロイは未実施。

## 公開判断との境界

この改善は本番の登録・メール・決済・発信を有効にしない。固定 HTTPS・常設配備、実メール、実 Stripe、公式 Claude Code / ChatGPT の接続、同意された実営業電話は別の受け入れ条件。[一般向けサービスの公開条件](public-service.md)と[MCP の検証範囲](sales-mcp.md)を継続する。

本番の実ユーザーによる成功率、iOS/Android 実機、実回線での速度、支援技術の実利用、審査員の評価は、このローカル Chrome / macOS Safari 検証だけで証明できない。ローカル画面の改善と観測済み不具合の修正は完了したが、受賞水準への到達を認定した状態ではない。
